- **微信小程序定制开发**：从 0 到 1，含 UI 设计、前后端开发、上线部署、备案、运维

## 合作流程

```
1. 需求沟通（免费）   →  确认核心目标、用户场景、预算区间
2. 方案与报价（1-3 天） →  产出功能清单 + 原型草图 + 报价分项
3. 合同签订            →  分期付款，按里程碑结算
4. 设计与开发（2-8 周） →  每周同步进度，关键节点 Demo 演示
5. 测试与上线          →  含小程序备案、审核、灰度发布
6. 运维与迭代          →  默认含 1 个月免费维护，长期合作可签运维协议
```

## 关于报价

小程序定制开发的价格区间跨度很大，主要看：

- **功能复杂度**（页面数、交互复杂度、是否含 IM/直播/AI）
- **后端逻辑**（是否需要复杂业务系统、是否对接第三方）
- **设计要求**（套模板 vs 完全定制 UI）
- **上线后是否含运维**

**常见区间参考**：

| 类型 | 价格区间 | 周期 |
|------|---------|------|
| 简单展示型（5-10 页） | ¥1 万 - ¥3 万 | 2-3 周 |
| 标准工具/内容型 | ¥3 万 - ¥8 万 | 4-6 周 |
| 含后台的电商/服务型 | ¥8 万 - ¥20 万 | 6-10 周 |
| 复杂业务系统型 | ¥20 万+ | 8 周+ |

> 具体报价以详细需求沟通后的方案为准。
